1. 4f architecture and model boundary

  1. Scientific question: Where does the classical model end?
  2. Variables and units: Position in mm, wavelength in nm; ηtotal dimensionless.
  3. Independent / controlled variables: Configured grid, focal length, channel and detector efficiencies.
  4. Observed result: Configured λ=1550 nm; grid N=128; optimized ηtotal=0.325457.
  5. Physical mechanism: A sampled Fourier transform, pupil and phase mask determine projection onto the LO; Gaussian sampling follows.
  6. Possible falsification: Failure of power/overlap tests would invalidate the optical-to-statistical interface.
  7. Limitations / artifacts: Diagram is an operator schematic, not a finite-distance lens-by-lens experimental validation.
  8. CGH / TFLN implications: Bulk lenses expose a Fourier plane; an integrated slab/star coupler requires independent design.

2. Spatial intensity and phase

  1. Scientific question: How are intensity and phase redistributed?
  2. Variables and units: Intensity in m⁻², coordinates mm, wrapped phase rad.
  3. Independent / controlled variables: Same source and optimized mask; Fourier coordinates use a different physical pitch.
  4. Observed result: Source power=1; optimized output power=1.
  5. Physical mechanism: FFT scaling dx/dxF preserves integrated power between physical planes.
  6. Possible falsification: A mismatch between integrated powers beyond pupil loss would falsify normalization.
  7. Limitations / artifacts: Common linear intensity scale may hide weak Fourier detail; phase below 10⁻⁶ peak intensity is masked.
  8. CGH / TFLN implications: CGH aperture and detector area must be specified in physical coordinates.

3. Correction comparison and residual phase

  1. Scientific question: Does phase correction improve mode matching?
  2. Variables and units: Intensity m⁻²; LO-relative residual phase rad; overlap dimensionless.
  3. Independent / controlled variables: Same representative distorted input, pupil and LO; correction method changes.
  4. Observed result: ideal: ηmode=1.00000, Topt=1.00000; distorted: ηmode=0.40941, Topt=1.00000; analytic: ηmode=0.45290, Topt=1.00000; optimized: ηmode=0.45202, Topt=1.00000; lossy: ηmode=0.20200, Topt=0.06174
  5. Physical mechanism: A Fourier phase can align spectral phase but cannot match arbitrary spectral amplitudes.
  6. Possible falsification: Independent test realizations can show no improvement or worse generalization.
  7. Limitations / artifacts: Representative maps are not population averages; global overlap phase is removed only for residual visualization.
  8. CGH / TFLN implications: Residual phase and amplitude both matter; a phase-depth calibration alone cannot guarantee coupling.

4. Optimized Fourier-plane phase mask

  1. Scientific question: What phase pattern was selected?
  2. Variables and units: Fourier coordinates mm; wrapped phase rad; histogram pixel counts.
  3. Independent / controlled variables: Validation-selected continuous phase; fixed sampling and pupil.
  4. Observed result: Wrapped phase range [-3.13482, 3.12529] rad; Fourier pitch=100.911 µm.
  5. Physical mechanism: Unit-modulus modulation changes phase, not local Fourier intensity.
  6. Possible falsification: Quantization or measured phase errors can reduce held-out overlap.
  7. Limitations / artifacts: Histogram includes unilluminated pixels; no lithographic feature or quantization constraint was optimized.
  8. CGH / TFLN implications: No dimensioned etch height is exported without material indices and process calibration.

5. Training and held-out validation

  1. Scientific question: Does optimization generalize beyond training?
  2. Variables and units: Iteration index; mean normalized overlap.
  3. Independent / controlled variables: Independent train/validation seeds; multiple initialization seeds; fixed optimizer settings.
  4. Observed result: Selected initialization=2, iteration=54, validation overlap=0.455778; independent optimized test mean=0.470226.
  5. Physical mechanism: Autograd adjusts phase using training gradients; validation chooses the checkpoint.
  6. Possible falsification: Poor independent test overlap would contradict robust generalization.
  7. Limitations / artifacts: Initialization envelopes are ranges, not statistical confidence intervals; validation selection can overfit.
  8. CGH / TFLN implications: Training should include measured alignment and fabrication errors before manufacturing.

6. Misalignment and aberration robustness

  1. Scientific question: How sensitive is overlap to displacement and defocus?
  2. Variables and units: Displacement µm, defocus coefficient rad, overlap dimensionless.
  3. Independent / controlled variables: Only displacement x and defocus are swept; other distortions fixed; no retraining.
  4. Observed result: distorted: sweep min=0.04247, max=0.80529; analytic: sweep min=0.04559, max=0.80731; optimized: sweep min=0.04538, max=0.82041
  5. Physical mechanism: Displacement changes Fourier phase while aberration changes the complex spectrum.
  6. Possible falsification: A measured tolerance scan outside simulated trends would reject the distortion model.
  7. Limitations / artifacts: Finite deterministic grid is not an uncertainty distribution or complete tolerance budget.
  8. CGH / TFLN implications: Use this scan to propose alignment tests, not to certify manufacturing tolerances.

7. Calibrated one-quadrature homodyne

  1. Scientific question: Do calibrated homodyne ensembles follow the Gaussian model?
  2. Variables and units: Quadrature divided by measured vacuum standard deviation; probability density.
  3. Independent / controlled variables: Independent noise streams; V_A=4, receiver noise=0.02, electronics=0.01.
  4. Observed result: ideal: N=100000, vacuum calibration=1.00475; distorted: N=100000, vacuum calibration=1.00134; analytic: N=100000, vacuum calibration=1.01002; optimized: N=100000, vacuum calibration=1.00508; lossy: N=100000, vacuum calibration=0.996482
  5. Physical mechanism: Unconditional variance includes modulation; signal-subtracted residual contains shot, excess and electronic noise.
  6. Possible falsification: Non-Gaussian residuals or disagreement with the analytic overlay would challenge this sampler.
  7. Limitations / artifacts: Conditional histograms select archived symbols with |Alice X| ≤ 0.1√V_A; finite-bin width and any uncompensated P rotation remain. Residual is a separate latent-noise diagnostic. Scatter pairs prepared Alice X with one Bob quadrature across symbols, not simultaneous X/P heterodyne.
  8. CGH / TFLN implications: TFLN IQ encoding and balanced homodyne require independent vacuum and electronics calibration.

8. Variance and uncertainty

  1. Scientific question: Are empirical variances consistent with predictions?
  2. Variables and units: Nominal shot-noise units; approximate 95% sample-variance intervals.
  3. Independent / controlled variables: Same optical efficiencies and Gaussian modulation; independent ensembles per case.
  4. Observed result: ideal: empirical−theory=+0.018231, theory inside CI=True; distorted: empirical−theory=+0.0022151, theory inside CI=True; analytic: empirical−theory=+0.0095823, theory inside CI=True; optimized: empirical−theory=+0.0013719, theory inside CI=True; lossy: empirical−theory=-0.0042157, theory inside CI=True
  5. Physical mechanism: Var(Y)=ηtotal V_A+1+ξrec+vel; reduced unconditional variance alone does not imply squeezing.
  6. Possible falsification: Systematic disagreement beyond sampling uncertainty would indicate a model or normalization error.
  7. Limitations / artifacts: Normal-approximation intervals omit calibration uncertainty and multiple-comparison corrections.
  8. CGH / TFLN implications: Measure LO stability and shot-noise linearity before interpreting receiver variances.

9. SNR and efficiency budget

  1. Scientific question: How do overlap and throughput jointly control SNR?
  2. Variables and units: Linear efficiencies and homodyne SNR dB.
  3. Independent / controlled variables: Fixed channel, detector, modulation and noise; case-dependent overlap and optical throughput.
  4. Observed result: ideal: SNR=2.79612 (linear); distorted: SNR=1.14475 (linear); analytic: SNR=1.26636 (linear); optimized: SNR=1.26391 (linear); lossy: SNR=0.0348694 (linear)
  5. Physical mechanism: ηtotal=Tchannel Topt ηmode ηdetector; the factors multiply, rather than add.
  6. Possible falsification: A passive device increasing power above its input would violate this model.
  7. Limitations / artifacts: Zero SNR is rendered at the floating-point floor in dB; mutual information is classical and not a key rate.
  8. CGH / TFLN implications: Optimize insertion loss alongside mode matching; phase cannot restore occluded photons.

10. Gaussian pure-loss validation

  1. Scientific question: Does coherent-state pure loss preserve vacuum variance?
  2. Variables and units: Transmissivity dimensionless; quadrature mean and variance SNU.
  3. Independent / controlled variables: Input mean (2, −0.8), covariance identity; independent Monte Carlo samples.
  4. Observed result: Backend: Strawberry Fields gaussian (isolated subprocess); maximum mean error=0.00656945; maximum variance error=0.00776008.
  5. Physical mechanism: μout=√T μin and Vout=T Vin+(1−T)I; a coherent state retains variance 1.
  6. Possible falsification: A reproducible T-dependent coherent variance would falsify the pure-loss implementation.
  7. Limitations / artifacts: SF Gaussian engine validated vacuum and coherent pure-loss moments; empirical homodyne arrays are seeded NumPy samples. Backend identity is archived, not inferred from the rendering environment; no quantum-security simulation is claimed.
  8. CGH / TFLN implications: Loss characterisation is required for a TFLN transmitter; a passive CGH cannot generate squeezing or entanglement.
