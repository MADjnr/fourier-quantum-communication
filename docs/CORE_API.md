# Core API (integration contract)

Validation additions: `torchoptics_validation` includes `fresnel_relative_error`, comparing official TorchOptics v0.4.0 `Field.propagate_to_z(..., propagation_method='ASM_FRESNEL', asm_pad_factor=0)` with a separate NumPy transfer-function reference. Both use periodic boundaries; this is not validation of a full finite-window lens-by-lens TorchOptics relay. The production 4f relay remains an exact sampled Fourier operator with PyTorch autograd, independently normalized against TorchOptics. Official API sources checked: https://github.com/MatthewFilipovich/torchoptics/blob/v0.4.0/torchoptics/fields.py and https://github.com/MatthewFilipovich/torchoptics/blob/v0.4.0/torchoptics/propagation/angular_spectrum_method.py .

Homodyne `mutual_information_bits` uses Alice's **matched rotated quadrature**. New `mutual_information_alice_x_bits` and `snr_alice_x_theory` refer specifically to unrotated X_A, and include P_A leakage as noise when phase compensation is disabled. `simulate_homodyne` additionally returns `rotated_alice` in its arrays. These are classical mutual informations, never secret-key rates.

`from src.experiment import run_experiment`; `from src.config import load_config`.
`result = run_experiment(config)` returns `{"metrics": JSON-serializable dict, "arrays": dict[str, numpy.ndarray]}`. No disk writes. Config is a plain dict, defaults merged by load_config(path) / default_config().
Metrics: `cases` keyed ideal/distorted/analytic/optimized/lossy; each contains eta_mode, T_opt, c_real, c_imag, phase, eta_total and `homodyne` (theory/empirical variance, SNR, calibration, CI); `optimization` (seeds, selection, runtime); `quantum_validation`; `torchoptics_validation`; `sampling`; `config`.
Arrays: x_m, xF_m, source, lo, fourier_source; mask_analytic, mask_optimized; `{case}_output`, `{case}_fourier`, `{case}_homodyne`, `{case}_alice`, `{case}_residual`; train_curves, validation_curves (initializations x iterations); robustness_displacements_m, robustness_aberrations_rad, robustness_{distorted,analytic,optimized} (aberration x displacement); quantum_transmissivity, quantum_mean_theory, quantum_mean_empirical, quantum_variance_theory, quantum_variance_empirical.
All spatial fields complex; intensity = abs(field)**2, phase = angle(field). x and xF in meters, phases radians. Homodyne arrays one-quadrature X ensemble, NOT heterodyne. Main cases >=100000 symbols; scatter may downsample. `metrics` contains scalars/lists only; `arrays` suitable for np.savez_compressed. Optimizer selects initialization by held-out validation only; final metrics evaluated independent test distribution, with representative cases separately named.
